# RL 训练环境 —— ★ 实测可用的版本组合
#
# ============ 已验证组合（AutoDL PyTorch 2.5.1 + CUDA 12.4 镜像）============
#   torch        2.5.1+cu124   （镜像自带）
#   transformers 4.57.6        ★ 必须 <5
#   trl          0.19.1        ★ 必须 <=0.19.1
#   peft / datasets  最新即可
#
# ============ 为什么锁定这两个上界（三个坑的根因）============
#   坑 1: trl >= 0.20 会 import torch.distributed.fsdp.FSDPModule
#         → 该 API 是 torch 2.6+ 才有的，torch 2.5.1 报 ImportError
#   坑 2: transformers >= 5.0 把 _is_package_available() 的返回值
#         从 bool 改成 tuple (False, None)
#         → TRL 的 `if is_vllm_available():` 判断「非空元组」恒为真
#         → 没装 vllm 也去 import vllm → ModuleNotFoundError
#   共同根因：上游依赖只写了下界（transformers>=4.51），
#             pip 就装了 API 不兼容的新大版本。
#
# ============ 安装命令 ============
#   pip install "transformers<5" "trl==0.19.1" datasets peft
#
# ============ vLLM（可选，单独装）============
#   TRL 0.19.1 时代对应 vLLM 0.8.x（注意 vLLM 0.8 需要 torch>=2.6，
#   与本镜像的 torch 2.5.1 冲突 → 本环境不装 vLLM，用 --no-vllm）

transformers<5
trl==0.19.1
datasets
peft
